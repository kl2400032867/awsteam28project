# Secure Paid Content Delivery System (Frontend)

Modern React + Vite frontend for delivering private digital assets (e.g., PDF certifications) via **AWS CloudFront Signed URLs** generated by a Spring Boot backend.

---

## 🌟 Architecture Overview

```text
React Frontend (Vite)
       │
       │ GET http://localhost:8080/api/content
       ▼
Spring Boot Backend (Port 8080)
       │
       │ Generates CloudFront Signed URL (using RSA Private Key)
       ▼
CloudFront Signed URL (Returned to Frontend)
       │
       ▼
Browser opens URL in new tab
       │
       ▼
AWS CloudFront Edge (Verifies Signature & Expiration)
       │
       ▼
Amazon S3 Private Bucket (Content Streamed to Authorized Client)
```

---

## 🛡️ Enterprise Security Compliance

As per security best practices:
- **No private keys** (`private_key.pem`, RSA keys, AWS Secret Keys) are stored in the frontend.
- **Zero signing logic** resides in the browser.
- S3 bucket policy blocks public read access; content is exclusively accessible via CloudFront Origin Access Control (OAC) / signed requests.

## 🚀 Getting Started

### 1. Requirements
- Node.js (v18+)
- Your Spring Boot backend running on `http://localhost:8080` with endpoint `GET /api/content`

### 2. Run the Development Server

```bash
cd cloudfront-secure-content-ui
npm install
npm run dev
```

The application will start on:
`http://localhost:5173`

---

## ⚙️ Spring Boot Backend Connection

The frontend queries:
- **Primary:** `http://localhost:8080/api/content`
- **Fallback Proxy:** Vite dev server automatically proxies `/api` requests to `http://localhost:8080` to prevent any local CORS blocking.

### Tip for Spring Boot Controller CORS:
If you want to allow direct cross-origin calls from Vite:
```java
@CrossOrigin(origins = "http://localhost:5173")
@RestController
@RequestMapping("/api")
public class ContentController {
    @GetMapping("/content")
    public ResponseEntity<String> getSignedUrl() {
        String signedUrl = cloudFrontService.generateSignedUrl();
        return ResponseEntity.ok(signedUrl);
    }
}
```
